# 🎵 Spotify Frontend Clone

A responsive frontend clone of Spotify built using HTML, CSS, and JavaScript.

This project replicates Spotify's user interface and basic music player functionality to strengthen core frontend development skills.

## 🚀 Features
- Play / Pause functionality
- Interactive progress bar
- Dynamic song title updates
- Responsive layout
- Clean UI design inspired by Spotify

## 🛠 Tech Stack
- HTML5
- CSS3

## 📂 Project Structure
spotify-frontend-clone/
│── index.html  
│── style.css  
│── script.js  
│── /assets  
│── /songs  

## 🎯 Learning Outcomes
- DOM manipulation in JavaScript
- Handling audio elements with JS
- Responsive design principles
- Structuring and deploying projects on GitHub
